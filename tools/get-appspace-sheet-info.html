Get your Appspace token for the desk sheet

No developer tools needed — save a bookmark once, then click it whenever your token expires.

One-time setup: save the bookmark

  1. Show your bookmarks bar (usually Ctrl+Shift+B on Windows, or ⌘+Shift+B on Mac).
  2. Drag the button below into the bar — or right‑click it → Bookmark link / Add to favorites.

Appspace → Desk sheet info

If dragging doesn’t work: right‑click the button → save as bookmark. The bookmark must keep the whole address starting with javascript:.

When you need a new token

  1. Open Appspace and log in (same browser you use for work).
  2. Stay on an Appspace page (e.g. desk or home).
  3. Click the bookmark: Appspace → Desk sheet info.
  4. A panel opens with Copy buttons. Paste Appspace Token and Organizer ID into the Google Sheet.

You must be logged in on that Appspace site. If nothing happens, refresh, log in again, then click the bookmark.

Advanced: browser console (optional)

If the bookmark doesn’t work, use F12 → Console and the snippet in the project README.md under “Getting User Configuration from Browser (advanced)”.
